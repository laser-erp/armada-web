Отправить ветку на GitHub

Ветка: cursor/compliance-p0-4317 · репозиторий laser-erp/armada-perevozki

Срочно: репозиторий laser-erp/armada-perevozki сейчас публичный — любой может смотреть код. Закройте: Settings → внизу Danger zone → Change visibility → Make private.

Важно: ссылки на GitHub открывайте через Яндекс Браузер (на Android — красные кнопки ниже).

Сейчас: код на сервере aptown1 уже работает, но в GitHub ветка ещё не появилась — нужен один раз ключ с правом записи (Deploy key).

Шаг 1 — открыть настройки ключей

  1. Откройте настройки ключей в Яндекс Браузере:
Открыть Deploy keys в Яндекс Браузере

Или вручную: github.com → Settings → Deploy keys

  1. Если ключ armada-o02-20260827 уже есть — нажмите Delete (кнопки Edit в GitHub нет).
  2. Нажмите Add deploy key.

Шаг 2 — вставить ключ

  1. Title: armada-o02-20260827
  2. Key — скопируйте всю строку ниже (одна строка):
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAILSyvSZRK4RizqeFuS9KLzHa02nDPoZEyuwomCwrvFQM armada-o02-20260827
  1. Включите Allow write access → Add key.

Fingerprint для проверки: SHA256:GtLFE7XWrMJqaqyFsIQRjXei8E4oW/wK+X29JWvAxuI

Шаг 3 — сообщить агенту

  1. Напишите в Cursor: «ключ добавил, запушь на GitHub».
  2. Агент отправит ветку автоматически.

Альтернатива — через программиста

Если ключ не хотите добавлять: программист скачивает файл bundle (это файл, не страница) и выполняет команды git на своём ПК.

Скачать bundle-файл 
curl -fsSLO https://aptown1.fvds.ru/downloads/armada-compliance-4317.bundle
git fetch ./armada-compliance-4317.bundle cursor/compliance-p0-4317:cursor/compliance-p0-4317
git push -u origin cursor/compliance-p0-4317
