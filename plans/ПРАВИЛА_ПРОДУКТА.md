## 4. Водитель (`/v`)

### 4.1. ЕТО и смена

| Правило | Статус |
|---------|--------|
| Перед выездом — ЕТО (осмотр) | согласовано |
| Одометр ЕТО = старт дня для «Км сегодня» | согласовано |
| **Автозакрытие смены:** если машина **не загружена** — закрывать (даже без одометра стоянки в момент ухода) | согласовано · не в коде |
| Если машина **загружена**, заказ открыт — смену **не** закрывать как пустую (ночёвка с грузом, перенос выгрузки, вечерняя погрузка → утренняя выгрузка) | согласовано · не в коде |

### 4.2. Утро: ЕТО и вчерашняя смена

| Правило | Статус |
|---------|--------|
| Ввели первый одометр ЕТО → сравнить с **последним в системе** по этому ТС | согласовано · не в коде |
| Если **больше** → эту цифру одометра записать в **вчерашнюю** смену; закрыть смену **вчерашней датой** (не датой сегодняшнего ЕТО) | согласовано · не в коде |
| Спросить **почему больше**: доехал до стоянки вчера / ездил без заявки (перегон) / ошибка в прошлых показаниях / другое (текст) | согласовано · не в коде |
| Если **равен** — без лишних вопросов | согласовано · не в коде |
| Если **меньше** — не принимать | согласовано · не в коде |

### 4.3. Одометры по рейсу

| Правило | Статус |
|---------|--------|
| Выезд со стоянки / прибыл на загрузку / выехал с погрузки (= в работе с грузом) / прибыл на выгрузку / стоянка | согласовано |
| «Выехал с погрузки» ≠ «прибыл на выгрузку» | согласовано |
| Загрузка и выгрузка — разные статусы | согласовано |

### 4.4. «Км сегодня» на главной

| Правило | Статус |
|---------|--------|
| **Км сегодня = последний введённый одометр − одометр ЕТО** | сделано (staging, build km-today-odo-v23) |
| Обновлять после **каждого** нового одометра (накопительно: 10 → 30…) | сделано |
| Путь до стоянки тоже должен попадать (когда есть одометр стоянки / закрытия) | согласовано · дожать |
| Не путать с расчётом ГСМ (см. §6) | согласовано |

## 5. Заказчик (`/z`)

| Правило | Статус |
|---------|--------|
| В кабинете видны **только** заявки, где эта компания — заказчик **или** грузоотправитель **или** грузополучатель (по id/ИНН). Чужие заявки — **никогда** | сделано (staging v24) |
| Пустые / неясные совпадения id — отбрасывать | сделано (staging v24) |
| Плашка «подписать T1/T3» — только если роль подходит (см. §7) | сделано (staging v24) |

---

## 6. ГСМ и деньги

| Правило | Статус |
|---------|--------|
| **ГСМ** = полный километраж заказа × л/100 км машины × цена литра | согласовано |
| Полный километраж = **нулевой до** + **с грузом** + **нулевой после** (до следующего заказа **или** до стоянки) | согласовано |
| Не считать ГСМ только «до выгрузки» / только по «Км сегодня» | согласовано |
| В коде сейчас часто неполная цепочка — **поправить** | согласовано · не в коде |
| Ставки, ЗП водителя, маржа логиста | уточнить |

---

## 7. ЭТрН и бумажная ТН

| Правило | Статус |
|---------|--------|
| T1 — **только грузоотправитель** (КЭП). Не заказчик «на всякий случай» и не чужой кабинет | сделано (staging v24) |
| T2 — перевозчик, приём на погрузке | согласовано |
| T3 — **только грузополучатель**. Грузоотправитель T3 **не** подписывает | сделано (staging v24) |
| T4 — перевозчик, выдача на выгрузке | согласовано |
| Выезд **со стоянки** — без обязательного T1 | согласовано |
| Выезд **с погрузки с грузом** — после T1 + T2 | согласовано |
| Если **заказчик и грузоотправитель — одно ЮЛ** → **бумажная ТН** (печать по форме), не ЭТрН T1 | сделано (staging v24) |
| Без КЭП у ГО — бумажная накладная на погрузке; ссылка в приложении не заменяет бумагу | согласовано |

## 8. Путевой лист

| Правило | Статус |
|---------|--------|
| По закону обязателен для выпуска на линию (259‑ФЗ ст. 6; приказ Минтранса № 390) | согласовано (Агент закон) |
| Может быть **бумажным или электронным** | согласовано |
| Обязательны показания одометра при **выпуске на линию** и при **возвращении с линии** | согласовано |
| В Армаде модуля путевого листа **пока нет** — нужно сделать | согласовано · не в коде |
| Данные смены/одометров должны кормить путевой | согласовано · не в коде |

## Очередь работ (из разговора)

1. **Баг утечки** `/z`: чужая заявка №10 у Стройтеха + роли T1/T3 + бумажная ТН при «заказчик = ГО»
2. **ГСМ** — полная цепочка км в расчёте
3. **Автозакрытие смены** + утренний ЕТО (вчерашняя дата)
4. **Путевой лист** в продукте
5. Дожать «Км сегодня» с путём до стоянки
