## Что уже выяснено (аудит без SSH)

### Домены и редиректы

| URL | Поведение |
|-----|-----------|
| `armada.sx` | **301** → `арендашаланды.рф` |
| `armada.sx/wp-admin` | **301** → `.рф/wp-admin` |
| Canonical, OG, sitemap | на **.рф** |
| `robots.txt` | `Host: https://armada.sx` — **конфликт** с canonical на .рф |

**Решение (согласовано):** канонический домен — **арендашаланды.рф**.  
`armada.sx` оставить **301 на .рф** (не наоборot). В SEOPress и sitemap — только .рф.

### robots.txt — срочно

- **`Crawl-Delay: 60`** — убрать (сильно тормозит индексацию).
- Закрыть от индекса служебные `/shortcode/…` (уже частично Disallow).
- Привести `Host:` к `https://арендашаланды.рф` (или убрать, если canonical везде .рф).

### Скорость — критично

- Главная ~**200 КБ**, отдача **очень медленная** (таймаут 45 с при загрузке админки).
- Apache **2.4.6**, PHP **7.4.33** (EOL).
- WordPress **6.6.2**.

### SEO / аналитика

- Плагин **SEOPress + SEOPress Pro** (6.7.2).
