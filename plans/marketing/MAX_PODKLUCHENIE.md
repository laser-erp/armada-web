# Подключение канала MAX — пошагово

**Инструкции (модель, тексты, ТЗ):** [MAX_ARMADA_PLAN.md](./MAX_ARMADA_PLAN.md)  
**Конкретные шаги с галочками:** [MAX_ARMADA_STEPS.md](./MAX_ARMADA_STEPS.md)

**Где настроить в приложении:** супер-админ → **Соцсети** → блок **MAX**.  
**API на сервере:** уже включён (`POST /armada-api/marketing/max/test`, publish, tick).

---

## Шаг 1. Канал в мессенджере MAX

1. Создайте **канал** (бизнес-профиль / «Каналы в MAX для бизнеса» — см. [dev.max.ru/docs/channels/create](https://dev.max.ru/docs/channels/create)).  
2. Запомните **название** и ссылку — их можно дать в постах TG/VK.

---

## Шаг 2. Бот и токен

1. Откройте [MAX для разработчиков](https://dev.max.ru) → **Чат-боты** → создайте бота (или используйте существующего).  
2. Скопируйте **токен** — надёжнее **выделить строку токена** в поле на dev.max.ru (обычно начинается с `AAH…`) и **Ctrl+C**. Кнопка «копировать» и toast «токен скопирован» — это не сам токен; если после вставки в АРМАДА поле пустое или короткое, скопируйте вручную.  
3. **Не** публикуйте токен в чатах и git.

---

## Шаг 3. Бот — администратор канала

1. В MAX откройте **ваш канал** → администраторы → **добавьте бота** с правом публиковать посты.  
2. Без этого API вернёт ошибку доступа.

---

## Шаг 4. Узнать chat_id канала

**Важно:** цифры из ссылки `max.ru/id…_biz` и ИНН **не** являются `chat_id` для Bot API. Из‑за них бывает ошибка `Chat not found`.

Проще всего в АРМАДА (супер-админ → Соцсети → MAX):

1. Сохраните **токен** бота.  
2. Бот — **админ** канала.  
3. Нажмите **«Найти chat_id»** — подставится число из событий MAX (иногда с минусом).  
4. **Сохранить MAX** → **Тестовый пост**.

Вручную (если кнопки нет): событие `bot_added` / `GET /updates` на [dev.max.ru/docs-api](https://dev.max.ru/docs-api) — поле `chat_id`. Схема: [max-messenger/api-schema](https://github.com/max-messenger/api-schema).

---

## Шаг 5. Ввести в АРМАДА

1. Войдите **супер-админ** → https://staging.app.armada.sx/a/ или https://app.armada.sx/a/  
2. Меню → **Соцсети** → **MAX**.  
3. Вставьте **access_token бота** и **chat_id** (из «Найти chat_id») → **Сохранить MAX**.  
   **Не** вставляйте ссылку на канал в поле токена.  
4. Нажмите **«Тестовый пост в канал»**.

Если ошибка:

| Текст | Что сделать |
|-------|-------------|
| `marketingMax не настроен` | Нажмите «Сохранить MAX» ещё раз |
| пустой token / chat_id | Заполните оба поля (chat_id — через «Найти chat_id») |
| `401` / `Invalid access_token` | Токен неверный — скопируйте заново с dev.max.ru |
| `Chat not found` | Неверный chat_id — «Найти chat_id», бот должен быть админом канала |
| `403` / access | Бот не админ канала |
| `fetch failed` / TLS | На VPS для **armada-api** нужен сертификат Минцифры: `NODE_EXTRA_CA_CERTS=/opt/armada-api/certs/russian_trusted_ca_bundle.pem` в `/etc/armada/api.env`, затем `systemctl restart armada-api`. Установка: `./scripts/install-max-api-ca-fvds.sh` |

---

## Шаг 6. Отложенные посты (позже)

В данных `marketingMax.queue` — очередь постов со статусом `scheduled` и временем `scheduledAt`.  
Кнопка **«Опубликовать due-посты»** или `POST /marketing/max/tick` публикует всё, у чего время наступило (если включена галочка **Автопубликация**).

Раздел «Маркетинг» в UI для очереди — см. [MARKETING_RAZDEL_APP.md](./MARKETING_RAZDEL_APP.md).

---

## Безопасность

- Токен хранится в **облачном state** (PocketBase), видит только супер-админ в форме.  
- Не дублируйте токен в `store.js` и на GitHub.
