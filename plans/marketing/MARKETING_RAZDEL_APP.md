# Раздел «Маркетинг» в приложении — как это будет работать

**Для кого этот текст:** вам как владельцу — без кода, цельная картина.  
**Статус:** **частично** — вкладка **«Соцсети»** (MAX + TG + VK); очередь постов TG/VK из одного черновика — **план**.

---

## 1. Зачем отдельный раздел, если есть «Активность»

| «Заявки на подключение» | «Соцсети» |
|-------------------------|-----------|
| Входящие pilot / kp-zakaz | Исходящие: MAX (API), TG/VK (пока вручную) |
| Подключить кабинет | План: текст + картинка + время + каналы |

Заказы transport → канбан «Входящие»; супер-админ **Активность** — онлайн и API.

---

## 2. Как вы будете работать (один человек)

```
┌─────────────────────────────────────────────────────────┐
│  Раз в неделю (45 мин)                                   │
│  Cursor → 2–4 черновика текста (FACTS + промпт)         │
└───────────────────────────┬─────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│  Админ → Маркетинг → «Новый пост»                        │
│  • текст (вставить из Cursor)                            │
│  • картинка: выбрать из галереи (01–08) или PNG         │
│  • контур: [Услуги] / [Платформа] → подставить CTA URL  │
│  • галочки: ☑ Telegram  ☑ VK  ☑ MAX                     │
│  • дата/время или «опубликовать сейчас»                  │
└───────────────────────────┬─────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│  Сервер (armada-api на VPS) — не в браузере!             │
│  По очереди шлёт в API мессенджеров с картинкой          │
└───────────────────────────┬─────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│  Подписчик кликает → order / pilot → снова «Активность»  │
└─────────────────────────────────────────────────────────┘
```

**Важно:** токены ботов **не** в `store.js` и не в браузере — только в `.env` на сервере (как ключи Контура).

## 3. Три канала — одна «коробка поста»

Один черновик в маркетинге → три доставки (можно не все сразу):

| Канал | Кто публикует | Что нужно один раз |
|-------|---------------|-------------------|
| **Telegram** | Бот-админ канала | Создать бота у @BotFather, добавить **админом** в канал, токен на VPS |
| **VK** | Сообщество | Токен сообщества с правом `wall`, ID группы |
| **MAX** | Бот в канале | Бот из [dev.max.ru](https://dev.max.ru), админ канала, `chat_id`, токен на VPS |

Техника (кратко):

- **Telegram:** `sendPhoto` + caption или `sendMessage` ([Bot API](https://core.telegram.org/bots/api)).  
- **VK:** `wall.post` (photo + text).  
- **MAX:** `POST https://platform-api2.max.ru/messages` — text + attachments после загрузки файла ([доки MAX](https://dev.max.ru/docs-api/methods/POST/messages)).

В интерфейсе маркетинга вы **не видите** токены — только статус: «TG ✓ подключён», «MAX — нет chat_id».

## 4. Экраны раздела «Маркетинг» (план UI)

### 4.1. Очередь постов

- Черновик → Запланирован → Опубликован / Ошибка  
- Кнопки: редактировать, дублировать, отменить план  

### 4.2. Новый пост

- Поле текста (лимиты: TG 1024 с фото, VK длиннее — UI может предупредить)  
- **Галерея картинок:** превью `marketing-cards` 01–08 + загрузка своего PNG  
- **CTA:** выпадающий список (order / pilot / kp-logist / …) → в конец текста дописать URL + UTM  
- **Каналы:** TG / VK / MAX  
- **Расписание**  

### 4.3. Каналы (только супер-админ)

- Подключить / проверить / «тестовый пост»  
- Не хранить токены в облаке sync клиента — только server-side  

### 4.4. Сводка (простая)

- Постов за месяц  
- Лиды order/pilot за месяц (из существующих данных «Активность»)  
- *Позже:* клики по UTM из Мetrika

## 5. Картинки «под каждый пост»

| Уровень | Как |
|---------|-----|
| **Сейчас (без раздела)** | HTML-карточки `web-preview/marketing-cards/` → PNG скриптом или скрин; вручную в TG/VK/MAX |
| **С разделом** | В «Новый пост» → «Картинка 04 — шаланда» → сервер подставляет файл из `/marketing-cards/png/` или CDN |
| **Идеал** | Cursor в промпте пишет: «картинка: 04» — вы в UI одним кликом |

Карточки — **макеты**; живые скрины prod можно **загрузить** в галерею позже.

## 6. Этапы внедрения (чтобы не утонуть)

### Этап 0 — сейчас, без программирования

- [FACTS](./templates/ARMADA_FACTS_TEMPLATE.md) + [промпт недели](./templates/CURSOR_WEEKLY_BATCH.prompt.md)  
- [Картинки](./KARTINKI_K_POSTAM.md)  
- Отложенные посты **вручную** в TG/VK/MAX  
- Лиды — **Активность**  

### Этап 1 — «Маркетинг-lite» в админке

- Только **журнал черновиков** + галерея 01–08 + копировать «текст + ссылка»  
- Публикация **вручную**, но всё хранится в одном месте (sync облако)  

### Этап 2 — автопост на VPS

- `armada-api`: job «scheduled posts»  
- Интеграции TG → VK → MAX по очереди  
- Уведомление в админку: «опубликовано» / текст ошибки  

### Этап 3 — умнее

- Генерация черновика из FACTS кнопкой «Cursor» (прокси на server или вставка шаблона)  
- UTM в лидах order/pilot  
- Metrika  

**Для solo:** достаточно **0 → 1** на месяцы; **2** — когда надоело копировать в три приложения.

## 7. MAX отдельно

- Канал создаётся в MAX (бизнес-профиль / бот «Каналы» — см. [dev.max.ru/docs/channels](https://dev.max.ru/docs/channels/create)).  
- Бот с правами админа → `chat_id` → в настройках «Каналы» в маркетинге.  
- Лимиты: ~2 msg/sec на канал — для вашего ритма (2–3 поста/нед) irrelevant.  

Тот же текст, что TG, обычно подходит; VK иногда короче на 30% — в UI опция «вариант VK».

- Токены только `armada-api/.env`  
- Раздел «Маркетинг» — **супер-админ** или отдельная роль «редактор маркетинга» (позже)  
- В постах только то, что в **ARMADA_FACTS**
